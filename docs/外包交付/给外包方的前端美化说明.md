## 2. 怎么开始

### 2.1 本地跑起来

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8300
```

浏览器打开 `http://127.0.0.1:8300`。注册一个账号就能走完整流程。

### 2.2 改之前先跑一次基线校验

```bash
python scripts/check_frontend_contract.py
```

**期望输出：`PASS=10 FAIL=0 WARN=0`，退出码 0。**

如果 FAIL，说明你拿到的包有问题，先联系我，不要在此基础上改。

### 2.3 改造顺序

按这个顺序做，风险从低到高，每步都能单独验收：

1. **换配色** —— 只改 `:root` 里的变量值（见第 4 节），一次改动全站生效
2. **调排版** —— 间距、字号、行高、对齐、网格列数
3. **重做卡片 / 按钮 / 表单** —— 圆角、阴影、边框、hover 态
4. **响应式** —— 1440 / 768 / 390 三个宽度
5. **状态样式** —— 空状态、加载中、错误提示
6. **自检 + 交付**

## 5. 不能改的（踩一条即验收不通过）

### 5.1 功能锚点（自动校验会拦）

| 类别 | 数量 | 改了的后果 |
|---|---|---|
| 页面视图 | 8 个 `<section id="view-*">`，且必须是 `<section>` | 页面切换失效 |
| HTML `id` | 111 个 | 按钮看着正常，点了没反应 |
| JS 抓取的 `id` | 83 个 | 同上 |
| 内联 `onclick` | 37 个函数 / 99 处调用 | 按钮失效 |
| JS 函数 | 141 个，签名不变 | 逻辑报错 |
| API 路径 | 16 个路径 / 27 处调用 | 404 或 422 |
| localStorage 键 | 3 个：`wardrobe_token` / `wardrobe_uid` / `wardrobe_chat_sid` | 用户掉登录 |
| CSS 变量名 | 28 个（**值可改，名字不可改**） | 大面积样式失效 |

### 5.2 自动脚本查不到、人工必查的三条

这三条我方会人工抽查，请交付前自己过一遍：

1. **onclick 的参数不能改**。例如 `onclick="rateOutfit(this,'like')"` 改成 `onclick="rateOutfit(this,'dislike')"` 是禁止的。函数名对也不行，参数决定行为。99 处调用的参数一律原样保留。
2. **不许出现重复 `id`**。原版 111 个 id 互不重复。新增元素请用新 id 或只用 class，不要复制现有 id。浏览器遇到重复 id 取第一个，功能会静默失灵。
   自查命令（浏览器控制台）：
   ```js
   [...document.querySelectorAll('[id]')].map(e=>e.id).filter((v,i,a)=>a.indexOf(v)!==i)
   ```
   应返回空数组 `[]`。
3. **JS 依赖的这 10 个 class 不能改名**：`chip`、`msg-bubble`、`nav-item`、`opt-chip`、`outfit-note`、`rate-btn`、`rate-extra`、`rate-extra-input`、`seg-option`、`weather-stats`。JS 用 `querySelector('.xxx')` 抓它们，改了按钮失效，而且校验脚本查不到。

### 5.3 其他红线

- **不引入任何构建步骤**：不交 `dist/`，不要求我 `npm build`
- **不新增需要后端配合的改动**：不改接口、不新增接口、不改请求字段
- **不改 `frontend/` 目录结构**。若拆成 `index.html + app.css + app.js`，必须仍在 `frontend/` 下、入口仍是 `index.html`，并且**同时交一份合并好的单文件版**作为回滚备份
- 去掉 Google Fonts 必须给本地 fallback，不能出现方块字
- 不动 `app/`、`rules/`、`data/`、`docs/` 下的任何文件（**唯一例外**：`docs/frontend-contract/index-anchors.json` 只读）
