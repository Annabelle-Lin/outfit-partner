# 衣橱示例数据

> 项目：对话式穿搭推理 Agent（盘活用户已有衣物）
> 用途：给电子衣橱提供一批可直接导入/演示的单品图片与标签数据。
> 数据量：**50 件**，覆盖当前电子衣橱的 8 个品类。

## 一、文件夹结构

```
衣橱示例数据/
├── images/                 # 50 张单品图，文件名 = 编号_名称.jpg
├── 衣物标签表.xlsx          # 主表：衣物标签；附「字段说明」「图片来源」两个工作表
├── 衣物标签表.md            # 同一份数据的 Markdown 版（含图片预览）
└── README.md               # 本说明
```

## 三、字段口径

字段与「例子」中的衣物录入表单保持一致：

| 字段 | 取值 |
|---|---|
| 名称 | 自由文本，例：白色圆领短袖T恤 |
| 品类 | T恤 / 衬衫 / 裤子 / 裙子 / 风衣 / 毛衣 / 鞋子 / 配饰 |
| 主颜色 | 白色 / 黑色 / 灰色 / 藏青 / 浅蓝 / 牛仔蓝 / 卡其 / 米白 / 米色 / 燕麦色 / 棕色 |
| 季节 | 春秋 / 夏 / 冬 / 四季 |
| 版型 | 常规 / 修身 / 宽松 / 廓形 |
| 面料 | 纯棉 / 亚麻 / 牛仔 / 羊毛混纺 / 皮革 / 雪纺 等 |
| 适用场合 | 日常 / 通勤 / 旅游 / 运动 / 正式（多选，表中用 `/` 分隔） |
| 状态 | 可穿 / 清洗中 / 暂不可穿 |
| 备注 | 自由文本 |

## 四、使用方式

1. **演示录入**：按 `编号` 顺序逐件录入，图片选 `images/` 下对应文件；
2. **Excel 批量导入**：`衣物标签表.xlsx` 的「衣物标签」工作表可直接作为导入模板的数据区；
3. **推荐演示**：50 件单品覆盖上装、下装、外套、鞋、配饰，可组合出多套搭配；
   其中 `W006` 为「清洗中」、`W024` 为「暂不可穿」，用于验证“不可穿衣物不参与推荐”。

## 五、图片来源与版权说明

- 图片通过 Bing 图片搜索获取，优先选用 UNIQLO 官方商品图，以及 Clarks、ASICS、River Island 等品牌商品图；少量为白底商品图素材。
- 每件单品的检索词与来源站点见 `衣物标签表.xlsx` 的「图片来源」工作表。
- **这些图片仅用于课程项目界面预览与演示**，版权归原网站/品牌所有，不得用于商业用途。
- 项目技术选型不做 AI 图像识别，图片仅做前端预览，标签以本表为准。
