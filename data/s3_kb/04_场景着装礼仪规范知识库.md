## 4.1 着装基本原则（TPO / TPOR）

### K-ETQ-01　TPO 原则
TPO 原则指仪表修饰应随**时间（Time）、地点（Place）、场合（Occasion）**的变化而做相应调整。其中：
- **T（时间）**：服饰应顺应季节与时代特点；需考虑一天中早晚气温的变化与四季更替。
- **P（地点）**：应根据不同国家、民族、场所的特点选择不同的修饰手段，表示尊重。
- **O（场合）**：主要指日常生活与社会交往中的各类场所，大体分为**商务、社交、休闲**三大类，不同场合应选择不同的着装。商务场合宜着大方、端庄、规范的服装（制服、西装、中山装、套装、连衣裙）；社交场合宜典雅、时尚、个性（时装、礼服、民族服装）；休闲场合宜舒适、方便、自然（家居装、牛仔装、运动装）。

> 注：部分形象设计与礼仪教材将其扩展为 **TPOR 原则**，增加 **R（Role，角色）**，要求着装与自身社会角色相协调。本项目在 Agent 中采用四要素版本，因为"角色"恰好对应用户的身份标签（学生/上班族），对目标用户高度相关。
- [来源: S25｜杨菲《职业形象与服务礼仪》教材样章，第三章「着装修饰礼仪」第（五）条"TPO 原则"（T 时间／P 地点／O 场合）]
- [来源: S04｜张虹《服装搭配实务》第2版，项目四"服饰形象美学搭配"中"TPO 原则的服饰形象搭配技巧"章节]

### K-ETQ-02　TPOR 原则（四要素版）
着装要考虑**时间（time）、地点（place）、场合（occasion）、角色（role）**四要素，力求着装及其具体款式与这四者协调一致、和谐得配。
- **角色要素的具体化**：学生 → 休闲运动/学院风；职场新人 → 干练简约；面试者 → 稳重专业。
- [来源: S28｜TPOR 原则条目，MBA 智库百科（B 级来源，术语解释性）；A 级依据以 S25 的 TPO 原始表述为准，本条 R 要素的引入以此为参考并在文档中标注来源级别]

### K-ETQ-03　着装的其他基本原则
- **整洁原则**：任何情况下服饰应整洁，无污渍、无绽线、无破洞，扣子等配件齐全，衣领和袖口尤其注意整洁。
- **文雅原则**：商务场合着装应文明、大方，忌过于暴露（袒胸露背、暴露大腿、赤足、无袖露出腋窝、透视内衣）；过短服装（短裤、背心、超短裙、露脐装）不宜；不能单纯为追求线条而选择过于紧身或性感的服装。
- **得体原则**：仪表修饰应与自身性别、年龄、个性、气质相匹配，并与个人职业、身份等社会因素相匹配。
- **个性原则**：仪表修饰讲求艺术性，在造型、色彩、质地等方面贴近自己的体型、肤色和气质，掩饰缺陷、突出优势、体现个性。
- [来源: S25｜《职业形象与服务礼仪》样章，第三章第（一）～（四）条]
- [来源: S04｜《服装搭配实务》相关章节]

## 4.2 场合着装规范表（Agent 场合枚举值的直接依据）

### K-ETQ-04　三大类场合的着装规范对照

| 场合类别 | 典型子类 | 着装要求 | 禁忌 | 依据 |
|---|---|---|---|---|
| **商务/公务** | 上班通勤、会议、面试、洽谈 | 庄重、保守、传统；制服、工作服、套装、套裙 | 过于暴露、过于紧身/性感、图案杂乱、颜色过于跳脱 | S25、S04 |
| **社交** | 聚会、宴会、约会、婚礼 | 典雅、时尚、个性；时装、礼服 | 场合不匹配（如穿运动服参加宴会） | S25 |
| **休闲** | 居家、逛街、旅行、运动 | 舒适、方便、自然；家居装、牛仔装、运动装 | 正式场合穿居家/运动装 | S25 |
| **校园/学习** | 上课、自习、社团 | 简洁、舒适、得体；避免过于正式或过于随意 | — | S04（形象风格分类：休闲/中性） |

- **Agent 实现**：场合输入模块的枚举值 = 上表"典型子类"，Agent 内部映射到"类别 + 正式度等级（1~5）"。

- [来源: S04｜《服装搭配实务》项目四任务12「TPO 原则的服饰形象搭配技巧」]

### K-ETQ-05　正式度分级（工程化规则）
为便于排序，将场合映射为**正式度等级 formal_level ∈ {1..5}**：

| 等级 | 场合示例 | 允许廓形 | 允许设计款数量 | 允许图案 |
|---|---|---|---|---|
| 5 | 面试、正式商务会谈、婚礼、葬礼 | X 型收腰、H 型合体 | ≤1 | 素色为主 |
| 4 | 上班通勤、会议、见客户 | H 型合体、X 型、A 型 | ≤1 | 素色/细条纹 |
| 3 | 日常上课、社团活动、朋友聚会 | 全部 | ≤2 | 素色/小图案 |
| 2 | 逛街、旅行、约会 | 全部 | ≤2 | 可图案 |
| 1 | 居家、运动、宅 | 全部宽松 | 不限 | 不限 |

- **Agent 硬规则**：
  - `formal_level ≥ 4 时，设计款数量 ≤ 1；formal_level ≥ 5 时，图案单品数量 ≤ 1 且禁止大面积印花`
  - 正式场合配色三条硬约束（真题印证）：**以冷色调为主 / 采用经典深色系 / 降低色彩纯度**
  - 正式场合裙长：职业套裙标准式短裙约 **40cm**
- [来源: S25｜《职业形象与服务礼仪》样章，商务场合着装禁忌条款；S04｜《服装搭配实务》项目四 TPO 搭配技巧]
- **工程化说明**：五级分层为项目自建的分级方法，其**约束内容**（商务场合的保守性要求）来自 S25 / S04 原文，**分级粒度**为本项目为可计算而做的归纳，已在文档中明示。
- [真题印证: S35｜《职业技能等级认定指导手册 形象设计师（五级）》单选第209题「严肃职业女装色彩应当以冷色调为主」、第210题「职业男装配色以经典深色系为典型」、第227题「职业女装标准式套裙的短裙长度一般在 40cm 左右」、判断题第38题「商务洽谈场合的职业妆用色应降低色彩的纯度」——见 07 文件 K-EXM-04、K-EXM-05]

## 4.3 天气适配（与气象行业标准对齐）

### K-WEA-01　穿衣气象指数的定义
穿衣气象指数是**表征人们在自然气候环境中着装厚薄程度的一种气象指标**，通过服装厚薄度判定，适用于公众气象服务。
- [来源: S22｜中国气象局公共气象服务中心、河北省气象服务中心《穿衣气象指数》行业标准，第2章术语和定义 2.1]

### K-WEA-02　服装厚薄度的计算要素
厚薄度 H 的计算综合考虑**气温 T、平均气温 Tm、空气相对湿度 rRH、风速 v** 等气象要素，其中湿度与风速对体感影响显著（湿度高时厚薄度需上调，风速大时需上调）。
- **Agent 意义**：本项目天气 API 返回温度、相对湿度、风速、降水概率，四个要素正好覆盖该公式的输入，可实现"体感温度"修正后再选衣物层数。
- [来源: S22｜《穿衣气象指数》第4章「服装厚薄度的计算」]

### K-WEA-03　穿衣气象指数 7 级划分与服务用语
穿衣气象指数按服装厚薄度 H 划分为 7 级：

| 指数 | 厚薄度 H 区间 | 服务用语 |
|---|---|---|
| 1 | H > 25.0 | 适宜穿着厚羽绒服、戴手套等严冬装 |
| 2 | 15.0 < H ≤ 25.0 | 适宜穿着棉衣、皮衣，内着厚毛衣等冬装 |
| 3 | 8.0 < H ≤ 15.0 | 适宜穿着夹克衫外套等初冬装 |
| 4 | 4.0 < H ≤ 8.0 | 适宜穿着套装、夹克衫等早春晚秋装 |
| 5 | 1.5 < H ≤ 4.0 | 适宜穿着棉衫、长袖T恤、牛仔服等春秋装 |
| 6 | −1.2 < H ≤ 1.5 | 适宜穿着轻薄的衬衣和长裙等夏装 |
| 7 | H ≤ −1.2 | 适宜穿着短袖T恤、短裙、短裤等盛夏装 |

- [来源: S22｜《穿衣气象指数》第3章"穿衣气象指数判定"表1]
- **来源交叉印证**｜S23《常用生活气象指数服务产品等级划分》第3.3节给出的穿衣指数分级（1级 DSI>25 严冬装 … 7级 DSI≤−1.2 盛夏装）与 S22 完全一致，说明该口径为行业通行。

### K-WEA-04　Agent 采用的温度区间口径（与标准的关系说明）
中国气象局公共气象服务中心在科普口径中给出按**气温区间**的着装建议：

| 气温区间 | 着装建议 |
|---|---|
| < −10℃ | 厚羽绒服、加绒保暖衣、围巾、手套 |
| −10 ~ 5℃ | 羽绒服或棉衣、皮衣、毛衣 |
| 5 ~ 15℃ | 厚夹克、薄棉衣、毛衣 |
| 15 ~ 22℃ | 夹克、风衣、薄外套、针织衫 |
| 22 ~ 27℃ | 长袖T恤、衬衫、长裤 |
| 27 ~ 32℃ | 短袖、薄长裤 |
| > 32℃ | 短袖、短裙、短裤 |

- **口径差异说明（重要，答辩可能被问）**：S22/S23 使用"服装厚薄度 H"这一综合指标（内含湿度、风速修正），S27 使用单纯的"气温区间"。二者**不矛盾**：前者是精确算法，后者是科普简化。
- **本项目采用**：Agent 以 **S22 的 7 级指数为主规则**，在用户端输出时使用 **S27 的温度区间语言**（更易读），并在遇到高温高湿或大风等极端条件时，以湿度/风速对温度做体感修正后再匹配等级。
- [来源: S22｜《穿衣气象指数》第3、4章]
- [来源: S27｜中国气象局官网《气温程度划分》问答（2026-05-18 发布），中国气象局公共气象服务中心研发穿衣指数产品的说明]

### K-WEA-05　降雨与风力的场景影响
- **降雨**：淋湿后棉、麻等纤维素纤维湿态强度下降、保暖性显著降低；涤纶、锦纶及带涂层的面料抗湿性较好但湿气不易排出。雨天应避免"吸水易湿 + 保暖差"的组合，外层优先选防水/防风面料，内层选吸湿排汗。
- **风力**：风速增大显著降低体感温度（见 K-WEA-02 公式中 v² 项），≥5 级风时需增加外层防风；裙装需注意裙摆与走路姿态。
- **温差（日较差）**：一日温差 ≥10℃ 时推荐洋葱式穿法（内层排汗、中层保暖、外层防风）。
- [来源: S22｜《穿衣气象指数》第4章（风速对厚薄度的影响，公式分母含 0.01165v² 项）]
- [来源: S05｜朱松文、刘静伟《服装材料学》第5版（中国纺织出版社 2015，ISBN 9787518003617），纤维吸湿性能与湿态强度相关论述]
- [来源: S17｜GB/T 11048《纺织品 生理舒适性 稳态条件下热阻和湿阻的测定》]
