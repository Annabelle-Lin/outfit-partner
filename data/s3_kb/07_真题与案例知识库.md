#### K-EXM-02　真题印证：三色原则的量化面积比例（主色 60% / 辅色 30% / 点缀色 5–15%）
**单选题 221**：「主色是占据全身色彩面积最多的颜色，占全身面积的（ ）以上，通常作为套装、风衣、大 coat、裤子等。」

**单选题 223**：「（ ）在日常服装配色中只占全身面积的 5%-15%，可通过饰品来起到画龙点睛的作用。」
选项：A. 主色　B. 辅色　**C. 点缀色**　D. 无彩色

**单选题 222**：「低奢的日常服饰搭配风格往往需要（ ）的搭配方法，使得服搭色彩既稳重又有点睛的效果。」答案指向**点缀色**。

## 三、案例类（S36–S39）

### K-CAS-01　案例：面试着装 —— "白衬衫 + 黑套装"未必是最优解
**场景**：职场新人/大学生参加面试。

**行业观点**：不少职场新人默认选择"黑色套装 + 白衬衫"以体现专业形象。但这种搭配虽然不会出错，却容易在众多面试者中被淹没；在符合面试场合的前提下，适度展现个人独特魅力才能真正加分。

**给出的方案**：
1. **素色衬衫 + 学院风外套 + 深色基本款半裙** —— 衣橱中已有的素色衬衫或针织上衣搭配深色裙装即可，款式简洁、色彩不鲜艳（白/米/浅灰/深蓝均可）。需购置的仅是学院风外套（条纹镶边、双排扣等设计细节，色彩首选深蓝、白色），配一条丝巾即可。**该外套面试后仍可单独搭配日常装。**
2. **衬衫式连衣裙 + 纯色外套** —— 用衣橱中已有的基本款单色西装外套做外搭，内搭简洁的衬衫式连衣裙，用腰带、手包等基础配饰点缀。衬衫式连衣裙"性价比很高，穿性也很高"，外面配一件舒适短外套即为最好的休闲装。

**可提炼的规则**：
- 面试场合的合格区间很宽，**核心是"大方得体"而非"绝对正式"**；大学生不必刻意扮成熟。
- "用已有单品 + 只添置一件高复用单品"是理性的衣橱策略——**这一思路与本项目"盘活已有衣物"的核心目标完全一致**，是很好的价值论证材料。
- [来源: S36｜央视财经频道《购时尚》节目内容（CCTV 官网转载），《职场新人置装必备》专题]
- **来源级别：C（行业媒体案例）** —— 不作规则来源，仅作方案验证与演示脚本素材。

### K-CAS-02　案例：面试着装的分行业细分与"多一阶"原则
**场景**：面试着装的选择。

**行业细分**（以女性面试为例）：

| 行业 | 标准配备 | 示例造型 |
|---|---|---|
| 企业/金融/法律 | 合身套装、沉稳颜色（海军蓝/炭灰/黑）、端庄衬衫内搭、包头鞋 | 海军蓝或炭灰色裤装套装 + 白色丝质衬衫 + 尖头高跟鞋 + 皮革托特包 |
| 科技/初创 | 精致 smart casual，可省略全套西装 | 合身西装外套 + 精致衬衫 + 深色牛仔裤 + 乐福鞋或低跟鞋 |
| 创意产业 | 表达个人风格，仍需专业品质单品 | 别致的西装外套或夹克 + 时尚组合单品 + 亮点配饰 |
| 医疗保健 | 稳重专业、实用、鞋需包头 | 商务休闲风格单品 + 舒适平底鞋 |
| 教育 | 专业但亲切、方便活动 | 备战教师：专业连衣裙或组合 + 舒适鞋子 + 迎宾色彩 |

**"多一阶"原则**（来自服务业/零售业职场观察）：
- 公司日常穿 T 恤配牛仔裤 → 你穿素色衬衫配长裤
- 公司日常穿衬衫 → 你在衬衫外面加一件外套
- **"多一阶代表你重视这场对话，多两阶就变成不理解这个环境。"**

**可提炼的规则**：正式度不是绝对刻度，而是**相对于参照系（目标群体的日常着装）的一阶之差**。本项目 formal_level 机制可据此优化：用户可选"参照系"（互联网/传统/创意行业），Agent 输出"参照系 + 1 阶"。

### K-CAS-03　案例：真实场景的三体型改造方案（侧影视角）
**场景**：从侧面轮廓视角对三种常见身材痛点给出可执行的搭配改造方案。

**场景 A｜苹果型身材（腰腹有肉，四肢相对细）**
- 痛点：侧面看肚子突出，腰线消失
- 禁忌：紧身针织衫、高腰紧身裤、短款紧身上衣
- 方案：上衣选 H 型或微 A 字中长款衬衫/罩衫，长度过臀一半，**面料要硬挺、不要软塌塌贴肚子**；下装高腰直筒西装裤或烟管裤
- 关键细节：**上衣不要塞进去**，保持侧面一条垂直直线，只在胸前通过 V 领或项链制造纵向延伸
- 效果：侧面看是修长的长方形，完全隐藏腰腹起伏

**场景 B｜梨形身材（臀宽腿粗，上半身纤细）**
- 痛点：侧面看下半身厚重
- 禁忌：紧身铅笔裤、包臀裙、臀部有大口袋装饰的裤子
- 方案：上装选有设计感的泡泡袖或垫肩上衣（增加上半身量感）；下装 A 字伞裙（过膝）或阔腿裤
- 关键细节：利用"前后错落"——裙子选前短后长；裤子选垂坠感极好的面料，使侧面线条流畅下滑而非横向扩张

**场景 C｜H 型身材（上下一般粗，缺乏曲线）**
- 痛点：侧面看缺乏起伏，或因无腰线而显壮
- 禁忌：过于宽松的连体裤、没有结构的直筒大衣
- 方案：**制造曲线**——用腰带，但**不是勒紧，而是系在自然腰线偏上的位置**；层次叠加（内搭修身打底 + 外穿开衫或西装）；强调肩部线条，人为制造 X 型侧影

**易被忽略的破坏因素**：内衣轮廓外露（侧面剪裁简单的衣服如丝绸衬衫、贴身T恤，内衣边缘绝对不能露出）；斜挎包链条过长导致包身卡在髋骨位置，截断侧面线条显胯宽。
- [来源: S39｜光影艺境《学会这 3 个侧影显瘦技巧，穿衣不再显胖》专业穿搭内容平台文章（B 级，经验性内容）]
- **来源级别说明**：该来源为经验总结型内容平台，属 B 级。**本项目不将其作为规则来源**，但其"场景 × 痛点 × 禁忌 × 方案 × 关键细节 × 效果"的结构**高度适合作为 Agent 搭配理由的话术模板骨架**（见下方）。
- **交叉印证**：三个场景的禁忌项与 K-SHP-06 体型设计原则完全一致（苹果型忌贴身、梨型忌包臀、H 型忌全宽松），可作为规则回归测试用例。

### K-CAS-05　案例：气象部门的"互动式智能穿衣指数"——与本项目最接近的已有产品
**案例内容**：深圳市气象局发布的"互动式智能穿衣指数"，是**与本项目功能形态最接近的已落地公共气象服务产品**。

其关键做法：
1. **解决"体感温度与实际气温差异大"的问题**：结合气温、湿度、风力等气象要素，实现 **八级精细体感温度划分**，从"偏冷"到"偏热"，每一级体感对应具体的**衣物材质与穿搭款式**。
2. **按人群分化**：区分**职场男女、老年、儿童**等不同人群，分别提供当日、次日专属穿衣建议——"职场通勤讲究得体，老年人需要保暖舒适，儿童注重活动便利"。
3. **按场景覆盖**：覆盖日常通勤、居家出行等高频场景，适配晴天、阴天、雨天及夜间等天气条件，提供 **32 套不同的穿搭形象参考**。
4. **建立"用户反馈—快速迭代"闭环**：用户可对推荐"投票"，产品依据 **7500 余次用户反馈完成 5 轮优化迭代**。
5. **知识科普附加**：在服务界面加入"为什么夏天穿红色更防晒"等科普小知识。

- **对本项目的直接启示（三条，均可写进项目论述）**：
  1. **气象部门已经验证了"体感温度分级 + 人群分化 + 场景适配"这条路可行**，本项目的天气接入与人群/场合分档设计有公共服务实践背书。
  2. **"输出 32 套穿搭参考"证明"一次性给出多套方案"的交互形态是被验证过的**——本项目输出 3 套，套数更少但每套附推理理由，差异点在于**可解释性**而非数量。
  3. **"用户投票—快速迭代"闭环验证了反馈驱动的迭代机制有效**，本项目的"穿搭评价（喜欢/一般/不喜欢）"设计与其一致；其 5 轮迭代/7500 次反馈的量级也提示本项目**早期样本稀疏是正常的**，支持本项目在样本量小时采用计数法而非模型（K-ALG-08）的选择。
- [来源: S40｜中国气象局官网《深圳：互动式智能穿衣指数暖民心》新闻报道，A 级（官方机构发布）]
- **使用建议**：这是答辩时论证"我们的方案不是空想"的强力材料，建议在项目介绍 PPT 中引用。

### K-CAS-06　案例：其他气象服务中的场景化着装提示
