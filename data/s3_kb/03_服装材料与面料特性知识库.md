## 3.1 纤维与面料基础

### K-MAT-01　服装材料的构成层级
服装材料由**纤维原料 → 纱线 → 织物结构 → 后整理**四个层级构成，每一层级都决定服装的性能。织物按生产方式分为**机织物（梭织）、针织物、非织造布**；按组成材料分为天然纤维、化纤、混纺。
- **Agent 意义**：面料下拉标签应按"纤维成分 + 织物结构"两级组织，例如"羊毛针织物"而非笼统的"厚面料"。这两级直接决定后续保暖/透气判断。
- [来源: S05｜朱松文、刘静伟《服装材料学》第5版，中国纺织出版社 2015，ISBN 9787518003617，第1章服装用纤维原料、第2章纱线、第3章织物结构]
- [来源: S06｜王革辉《服装材料学》第3版，中国纺织出版社 2020，ISBN 9787518074204，绪论至第3章]

### K-MAT-02　梭织与针织的服用性能差异
机织物由经纬两个系列纱线交织而成，结构稳定、悬垂性好、尺寸稳定性好；针织物由线圈相互串套形成，横向弹性大、延伸性好、透气性好，但易变形、尺寸稳定性较差、易起毛起球。
- **Agent 硬规则**：正式场合（面试/商务）优先机织物；休闲/运动/长时间穿着优先针织物（弹性与舒适度）。可在话术中说明。
- [来源: S05｜《服装材料学》第5版第3章"机织物结构及特征""针织物结构及特征"]
- [来源: S06｜《服装材料学》第3版织物结构章节]

### K-MAT-03　纤维性能与气候适配
- **天然纤维**：棉（吸湿性好、透气、耐热但湿强下降）、麻（吸湿透气极佳、湿强高）、毛（羊毛吸湿保暖、弹性好）、丝（光泽好、吸湿）、竹纤维/莫代尔（再生纤维素，吸湿柔软）。
- **化学纤维**：涤纶（强度高、耐皱、尺寸稳定性好、吸湿差易闷热、易带静电）、锦纶（耐磨、弹性好）、腈纶（保暖、仿毛）、氨纶（弹性纤维）。
- **Agent 硬规则（体感适配）**：
  - 高温（≥28℃）：优先透气吸湿的麻、棉、莫代尔、粘胶；避免厚涤纶、灯芯绒、羊毛。
  - 低温（≤5℃）：优先羊毛、羊绒、羽绒、涤纶加绒；避免棉+麻单层（湿冷环境下保暖性差）。
  - 温差大（一日温差≥10℃）：推荐"洋葱式穿法"（内层排汗、中层保暖、外层防风），符合外层防风不透水、中层保温、内层吸湿的组合逻辑。
- [来源: S05｜《服装材料学》第5版第1章"纤维分类及其特征"、第1章第三节相关标准]
- [来源: S06｜《服装材料学》第3版"纤维服用性能分析"（体积质量、力学性能、热学性能、吸湿性能、表面性能）]

## 3.2 服装舒适性与功能性能

### K-MAT-04　透湿性与透气性（Agent 舒适度判据）
- **透气性**：织物在一定压差下单位时间通过单位面积的空气流量，单位 mm/s，测定方法见 **GB/T 5453《纺织品 织物透气性的测定》**。
- **透湿性**：水蒸气透过织物的能力，单位 g/(m²·24h)，测定方法见 **GB/T 12704.1/.2《纺织品 织物透湿性试验方法》**（吸湿法/蒸发法）。
- **Agent 意义**：这两项是"体感舒适"最可量化的织物指标。录入时不让用户填数值，而是让用户填"厚薄 + 有无网眼/有无涂层"的组合标签，Agent 映射到透气/透湿等级（见 3.5 映射表）。
- [来源: S15｜GB/T 5453《纺织品 织物透气性的测定》]
- [来源: S16｜GB/T 12704.1-2009 / GB/T 12704.2-2009《纺织品 织物透湿性试验方法 第1部分：吸湿法／第2部分：蒸发法》]

### K-MAT-05　热阻与湿阻（生理舒适性核心指标）
在稳态条件下测定织物及成品的**热阻（clo/m²·K）与湿阻**，是评价服装整体隔热与透湿性能的标准化方法。
- **Agent 意义**：理论上可直接作为"这件外套在 X℃ 是否够暖"的计算依据；但受版型、层数、覆盖面积影响极大，本项目采用**"分层保暖度估算"**而非精确热阻计算，见 K-MAT-06。
- [来源: S17｜GB/T 11048《纺织品 生理舒适性 稳态条件下热阻和湿阻的测定》]

### K-MAT-06　分层保暖度估算（工程化规则）
工程上采用"保暖层级"近似模型：以**外层 / 中层 / 内层**三槽位分别赋予保暖指数，再按气温区间决定所需层级。
- 规则来源：气象行业标准《穿衣气象指数》用"服装厚薄度 H"划分为 7 级并给出对应着装建议（见 `04_场景着装礼仪规范知识库.md` K-WEA-04），本项目据此反推各温度段所需层级。
- [来源: S22｜中国气象局公共气象服务中心等《穿衣气象指数》行业标准，第3章"穿衣气象指数判定"、第4章"服装厚薄度"；由 K-WEA-04 转引]

### K-MAT-07　吸湿性
纤维的吸湿性以**吸湿率（%）**表示，标准测定方法见 **GB/T 21655.1《纺织品 吸湿率的测定》**。纤维素纤维（棉、麻、 viscose/莫代尔）吸湿性显著优于涤纶。
- **Agent 规则**：长时间户外或运动场景 → 优先吸湿率高的纤维；雨天 → 涤纶/PVC 涂层面料抗湿但闷，棉麻淋湿后保暖性大幅下降（湿态强度下降，见 K-MAT-03）。
- [来源: S18｜GB/T 21655.1《纺织品 吸湿率的测定》]

### K-MAT-08　抗起毛起球与耐磨性
起球与耐磨性是外套、针织衫长期穿着后的关键质量指标。**GB/T 4802.1《纺织品 马丁代尔法耐磨性能测定》**规定了起毛起球与耐磨的测定方法。
- **Agent 意义**：新品购前评估中，若推荐同类单品，应优先推荐"耐穿度更高"的选项；也可在长期反馈中记录"穿了 3 次起球"作为负反馈特征。
- [来源: S19｜GB/T 4802.1《纺织品 马丁代尔法耐磨性能测定》（含起球等级评定）]

### K-MAT-09　力学性能（拉伸/撕破/顶破）
- **GB/T 3923.1**《纺织品 织物拉伸性能 第1部分：断裂强力和断裂伸长率的测定（条样法）》
- **GB/T 19976**《纺织品 顶破强力测定》（针织面料常用）
- **接缝性能**：GB/T 13773 系列《纺织品 织物及其制品的接缝拉伸性能》
- **Agent 意义**：作为"耐穿度"标签的客观依据；不建议用户上传照片判断，故以面料标签为主来源。
- [来源: S20｜GB/T 3923.1-2013《纺织品 织物拉伸性能 第1部分：断裂强力和断裂伸长率的测定》]

### K-MAT-10　绒类面料特性
摇粒绒表面经磨毛形成小球球，蓬松柔软、保暖性好，常用于外套内胆；天鹅绒手感柔软、厚实坚牢、绒毛浓密、保温性好，常用于外衣面料、衣领帽子。羊毛针织呢绒兼具光泽柔和、悬垂性好、透气性强、不缩水。
- **Agent 规则**：冬季外套保暖层级排序建议：羽绒/羊绒 > 摇粒绒内胆 > 厚涤纶针织 > 灯芯绒。摇粒绒宜作"中层内胆"而非外层（外层耐磨性不足）。
- [来源: S05｜《服装材料学》第5版"服装典型品种的选材"相关章节；材料目录与品种说明部分]

## 3.3 安全与合规（新品评估模块的硬约束）

### K-MAT-11　GB 18401《国家纺织产品基本安全技术规范》
适用于 14 周岁及以上人群使用的服用、装饰用和家用纺织产品，考核**甲醛含量、pH 值、染色牢度、异味、可分解致癌芳香胺染料**等项目，并按直接接触皮肤程度分为三类：

| 类别 | 适用对象 | 甲醛限值 | pH 值 |
|---|---|---|---|
| A 类 | 直接接触皮肤（婴幼儿及贴身穿着） | ≤20 mg/kg | 4.0～7.5 |
| B 类 | 直接接触皮肤（成人内衣、T恤、睡衣、床品等） | ≤75 mg/kg | 4.0～8.5 |
| C 类 | 非直接接触皮肤（外套、大衣、窗帘等外用品） | ≤300 mg/kg | 4.0～9.0 |

可分解致癌芳香胺染料为**禁用物质，不得检出**。
- **Agent 硬规则**：新品评估模块在录入"参考图 + 标签"时增加一栏"安全类别（A/B/C）"，作为**信息项而非校验项**——本项目不做图像识别也无法核验吊牌，故仅提示用户查看吊牌。
- [来源: S12｜GB 18401-2010《国家纺织产品基本安全技术规范》]

### K-MAT-12　GB 31701《婴幼儿及儿童纺织产品安全技术规范》
适用于 0～14 周岁婴幼儿及儿童纺织产品，在 GB 18401 基础上增加**耐湿摩擦色牢度、重金属（铅、镉）、邻苯二甲酸酯、燃烧性能**等要求；婴幼儿（36 个月及以下）纺织产品应符合 A 类并标注"婴幼儿用品"。
- **Agent 意义**：目标用户含大学生，衣物多为成人款，但用户可能为婴幼儿亲属采购——本条作为知识库储备与"适用年龄"标签的取值依据。
- [来源: S13｜GB 31701-2015《婴幼儿及儿童纺织产品安全技术规范》]

### K-MAT-13　面料制品的标签与标识合规
服装成品上号型规格、纤维成分、洗护方法等必须缝制在永久性水洗标上；厂名厂址、执行标准、安全类别可印于吊牌或外包装；同一信息在不同载体上必须完全一致。
- **Agent 意义**：支撑"衣物录入的字段设计与国标标签对齐"，降低用户录入时"不知道填什么"的困惑；也是"为什么我们不上传图片也能保证属性准确"的依据——用户手上吊牌就有全部字段。
- [来源: S23｜中国质量新闻网《一分钟读懂衣服"身份证"》，对 GB 18401 / GB 31701 标识规则的系统解读（B 级来源，用于理解性说明；规范本体以 S12、S13 为准）]

## 3.4 面料标签枚举值（供 S1/S2 落库）

| 字段 | 建议枚举值 |
|---|---|
| `fiber` 纤维成分 | 棉/麻/羊毛/羊绒/真丝/粘胶(人造棉)/莫代尔/涤纶/锦纶(尼龙)/腈纶/氨纶/混纺/其他 |
| `structure` 织物结构 | 梭织/针织/梭编针织/经编/毛毡/网眼 |
| `thickness` 厚薄 | 极薄(单层)/薄/中等/厚/加厚(夹棉/羽绒) |
| `texture` 手感与表面 | 光滑/柔软蓬松/硬挺有型/粗糙/起绒/针织纹理明显 |
| `function` 功能 | 基础/防风/防水/吸湿排汗/保暖/抗皱/免烫/抗菌(宣传)/其他 |
| `season_tag` 适温区间 | ≥28℃ / 22～28℃ / 15～22℃ / 8～15℃ / ≤8℃ |
| `care` 洗护 | 机洗/手洗/干洗/不可水洗 |
| `safety_class` 安全类别 | A/B/C/未知（不作强制校验） |

> `season_tag` 由用户自填或由 Agent 根据 `thickness + fiber + texture` 推断，用户可覆盖。

## 3.5 面料 × 气温 适配映射表（Agent 推理用，工程化规则）

> 依据：K-MAT-03 纤维性能 + K-MAT-02 梭织/针织差异 + K-WEA-04 穿衣气象指数分级
> 使用方式：`temperature_band → allowed (fiber, thickness) 组合 → 推荐槽位配置`

| 温度带 | 外层 | 中层 | 内层 | 下装 | 鞋 | 硬性禁止 |
|---|---|---|---|---|---|---|
| ≥28℃ | 无（防晒外套可选）| 无 | 棉/麻/莫代尔/粘胶薄针织或梭织 | 短裤/薄长裤/半裙 | 透气凉鞋/薄鞋 | 厚羊毛、灯芯绒、羽绒 |
| 22～28℃ | 薄防晒/薄衬衫 | 无 | 短袖/薄长袖 | 薄长裤/半裙 | 透气鞋 | 厚针织、皮革厚外套 |
| 15～22℃ | 衬衫+薄针织/薄风衣 | 薄开衫 | 长袖 T/衬衫 | 长裤/中长裙 | 运动鞋 | 羽绒、厚毛衣 |
| 8～15℃ | 风衣/夹克/薄呢大衣 | 毛衣/绒衫 | 长袖打底 | 长裤（可加绒） | 运动鞋/短靴 | 纯棉薄内搭（湿冷不保暖）|
| ≤8℃ | 羽绒/厚呢大衣/棉服 | 毛衣/摇粒绒内胆 | 保暖内搭 | 加绒长裤/厚牛仔裤 | 短靴/运动鞋 | 单层棉麻外穿 |
