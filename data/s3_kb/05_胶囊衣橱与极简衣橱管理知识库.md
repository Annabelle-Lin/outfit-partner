## 5.1 胶囊衣橱与极简衣橱管理理论

### K-CAP-01　胶囊衣橱的定义
胶囊衣橱（capsule wardrobe）指**一组最小量的服装单品，能够以多种方式相互混搭，组成大量视觉上协调的搭配**（a minimal set of garments that mix and match to compose many visually compatible outfits）。核心理念是"用更少做更多"（do more with less），属于极简与可持续时尚的范畴。
- **与本项目的关系**：本项目不生成胶囊衣橱，而是**反向使用**这一概念——用户已有衣橱就是既定的"集合"，Agent 的任务是最大化这个集合的**可搭配组合数**（搭配产出率），而非让用户买新衣。
- [来源: S29｜Hsiao W-L, Grauman K. *Creating Capsule Wardrobes from Fashion Images*. CVPR 2018，Abstract 与 Sec.1 Introduction]

### K-CAP-02　极简衣橱管理的实践原则
胶囊衣橱的实践原则可归纳为：确定核心色系与中性色基调；优先选择可跨季节搭配的经典单品；一件单品至少能与其他三件以上单品组合；避免一次性购买风格冲突的单品；按使用场景而非按类别组织衣橱。
- **工程化落点**：本项目"新品购前评估"模块正是把上述原则变成**购前拦截机制**——评估维度即"与现有衣橱的可搭配组合数增量"与"是否重复"。
- [来源: S29｜《Creating Capsule Wardrobes》第1章关于胶囊衣橱价值与已有做法的论述（面向消费者"用更少获得更多价值"）]
- [来源: S04｜张虹《服装搭配实务》第2版，项目三、项目四关于单品互搭与风格统一的方法性论述（教材侧佐证）]

## 5.2 搭配推理的学术方法（不使用图像的部分）

### K-ALG-01　搭配生成任务的形式化定义
学术上，"整套搭配生成"（Fashion Outfit Generation, FOG）指**将多个单品组合成一套搭配**的任务（区别于从零生成图像的纯视觉任务）。这类任务通常被建模为**检索问题**，其基本标准是：
- **类目完整性（completeness across categories）**：一套搭配需覆盖所需的各品类（外套、上装、下装、鞋、配饰）。
- **类目互斥（exclusivity within the category）**：同一品类槽位内只选一件。
- **搭配质量由单品间的兼容性（compatibility）决定**。
- [来源: S31｜Siddiquie et al. *Computational Technologies for Fashion Recommendation: A Survey*. arXiv:2306.03395，Sec.5 Fashion Outfit Generation 章节]

### K-ALG-02　兼容性建模的主流方法谱系
单品间兼容性建模方法包括：度量学习（metric learning）、孪生嵌入（Siamese embeddings）、链接预测（link prediction）、序列生成（RNN 按序逐件生成）、基于品类与属性的内容建模、以及借助领域知识（domain knowledge）辅助的建模。
- **本项目取用**：由于不做图像识别，**不采用视觉嵌入**；改用**属性标签的规则化兼容性**（本知识库领域一至四的内容），即"color/廓形/面料/场合的标签兼容矩阵"。这正是 K-ALG-01 中"类目完整性 + 类目互斥 + 兼容性"三要素的规则化实现。
- [来源: S31｜Survey Sec.5，compatibility modeling 相关综述]

### K-ALG-03　可解释性研究方向
近年研究强调搭配推荐的**可解释性**，通过注意力机制与可解释特征学习等手段，让模型给出的搭配理由更贴近人类可理解的维度（如品类关系、色彩协调、风格一致）。
- **本项目定位**：本项目**放弃黑盒可解释性路线**，采用**白盒规则 + 模板化话术**（每条规则输出对应一句理由），可解释性更强且实现成本更低。这是本项目在创新点上的差异化取舍。
- [来源: S31｜Survey Sec.5 关于 compatibility modeling interpretability 的讨论]
- [来源: S33｜宋雪萌等《基于时尚图谱增强的个性化互补服装推荐》，《信息安全学报》2021年第6卷第5期——关于利用属性知识与实体高阶关系提升搭配建模的思路]

### K-ALG-04　知识图谱与搭配规则推理
国内研究已尝试用**知识图谱**整合服装搭配领域知识，通过相似款匹配与历史搭配数据重用为用户提供搭配方案；亦有工作构建多模态知识图谱（融合文本属性与视觉信息）提升推荐的可解释性。
- **本项目取用**：本项目虽不上传图片做识别，但**用户录入的标签本身就是结构化属性**，可构造成一个轻量知识图谱（本体：单品—属性—属性值；关系：可搭配、适合同一场合、适配体型）。这与 S30/S31/S32 的思想一致，且实现成本远低于多模态方案。
- [来源: S30｜张理想、李沛儒、夏明《基于知识图谱的女装相似款匹配及搭配推荐》，《北京服装学院学报（自然科学版）》2023, 43(1): 41-49，DOI: 10.16454/j.cnki.issn.1001-0564.2023.01.007]
- [来源: S32｜万晓慧、李维乾、贺妮、邓玉琼《基于多模态知识图谱的服装推荐算法》，《计算机科学》（2025）——双策略知识图谱聚合优化思路]

### K-ALG-05　相似款匹配与"重复购买"判定
相似款匹配的目标是识别"用户已有单品中与拟购单品在关键属性上高度重合"的项。常用做法包括基于属性集合的 Jaccard 相似度计算。
- **本项目实现**：`重复度 = Jaccard(拟购单品的属性集合, 衣橱中同类单品属性集合)`，Jaccard 相似度定义为两个集合交并比 `|A∩B| / |A∪B|`。阈值取经验值，≥0.7 提示"高度重复"，0.5~0.7 提示"部分重复"，<0.5 视为可新增。
- **关键区分**（与"能不能搭配"是两个独立问题）：
  - 「重复度」高 → 劝退购买（钱花在重复的单品上）
  - 「可搭配性」低 → 劝退购买（买了也搭不起来）
  - 两者都低 → 建议购买（既不重复又能搭配现有衣橱）
- [来源: S30｜《基于知识图谱的女装相似款匹配及搭配推荐》，Jaccard 算法用于相似款筛选与匹配]

### K-ALG-06　搭配组合数与子集选择思想
胶囊衣橱生成被建模为**子集选择（subset selection）问题**：从大量候选单品中选出一个子集，使兼容性（quality）与多样性/通用性（versatility）最大化；使用次模函数最大化（submodular function maximization）可获得近似最优解，并可用贪心策略高效求解。
- **本项目借用**：同样用**贪心策略**解决组合爆炸——衣橱有 N 件单品时，理论搭配组合数为各槽位单品数的乘积（∏ N_i），实际不可枚举。本项目采用"先按规则剪枝（硬性规则过滤），再按偏好排序取 Top-3"的剪枝+排序策略。
- [来源: S29｜《Creating Capsule Wardrobes》第3章"Subset selection for capsule wardrobes"，次模目标与贪心/EM 式迭代求解]

### K-ALG-07　主体型建模对体型因素的处理
学术研究指出，体型（body shape）在穿搭推荐中长期被忽略近年才被重视；已有方法用多张照片的身体模型估计体型，或基于聚类的体型分配方案，但存在"照片中宽松衣物掩盖真实体型""明星体型过于完美、不代表普通人群"的局限。
- **本项目取用**：正是基于这一局限，本项目**放弃从照片推断体型**，改为**让用户直接填入胸围/腰围**（依据 S11 号型标准的 Y/A/B/C 分类），由系统计算体型代号。这是一个有明确文献依据支撑的产品决策，可在答辩中直接引用。
- [来源: S34｜Song X, Han X, Liu B, et al. *Personalized Capsule Wardrobe Creation with Garment and User Modeling*. ACM Multimedia 2019，Sec.2.1 User Modeling — Body Shape Modeling 部分]

### K-ALG-08　偏好学习的技术路径
用户偏好建模常用矩阵分解（MF）、BPR（贝叶斯个性化排序）等框架；本项目不训练模型，采用**基于反馈计数的可解释偏好权重更新**。
- **本项目实现（可解释优先）**：为每个属性值维护权重，如 `color_hue=黑` 的权重初始为 0，每次用户评价（喜欢/一般/不喜欢）分别 +1 / 0 / −1，加权近期反馈（如近 10 次权重占 0.7），归一化后用于候选排序。
- **选择理由**：用户样本量小（个人衣橱几十件）、反馈稀疏，训练模型会过拟合且无法解释；计数法在稀疏反馈下更稳健，且**用户能看到"因为你说过不喜欢黑色，我减少了黑色"**，符合本项目的可解释定位。
- [来源: S34｜《Personalized Capsule Wardrobe Creation》第2.1节 User Preference Modeling（MF / BPR / VBPR 谱系）]
- [来源: S33｜《基于时尚图谱增强的个性化互补服装推荐》——个性化互补推荐同时满足"与目标服装搭配"与"满足用户偏好"两个条件的双条件定义]

## 5.3 偏好优先级与决策机制

### K-PREF-01　三层偏好优先级（项目核心机制）
```
本次临时偏好（单次生效） > 长期历史偏好（学习所得） > 系统客观硬性规则（兜底）
```
- **实现要点**：硬性规则不是"最低优先级"，而是**先执行的过滤器**——不满足硬性规则的候选直接淘汰，不进入排序；只有通过硬性规则的候选，才按"临时偏好 > 长期偏好"的顺序排序。
- **可解释话术模板**：「这套方案满足了{硬性规则摘要}；并且按你本次选择的「{临时偏好}」做了优先考虑。」
- **依据**：硬性规则内容来自领域一至四（教材与标准）；优先级机制本身为本项目设计，对应项目创新点 3。
- [来源: 机制依据 K-COL-05、K-SHP-06/08、K-WEA-03、K-ETQ-04（均为教材/标准 A 级来源）；优先级排序逻辑为本项目设计]

### K-PREF-02　一次性输出 3 套差异化方案
由于审美具有主观性，系统不追求"唯一正确"，而是在合格方案中输出 3 套**有意差异化**的组合，把选择权交还用户。
- **差异化维度设计**：3 套方案应至少在以下两个维度上不同：
  1. **廓形路线**：修身利落 / 宽松舒适 / 直线廓形
  2. **色彩路线**：同色系深浅 / 中性色 + 一点亮色 / 冷暖对比
  3. **设计度**：全基础款 / 一件设计款点缀 / 基础款为主
- **硬性要求**：3 套方案必须**全部通过**第一层硬性规则（不能为了差异化而给出不合规方案）。
- [来源: 依据 K-COL-07/08（配色路线）、K-SHP-02/08（廓形路线）、K-COL-05（三色原则硬约束）]

### K-PREF-03　新品购前评估的判定逻辑
对拟购单品输出三结论：
| 结论 | 条件 | 话术方向 |
|---|---|---|
| 建议购买 | 重复度 < 0.5 且 可搭配组合数 ≥ 3 | 「它能和你现有的 {A}、{B}、{C} 分别搭配，{N} 种组合都能用上」 |
| 谨慎购买 | 重复度 0.5~0.7 或 可搭配组合数 = 1~2 | 「和你的 {X} 比较接近，且只能配 {Y} 一件」 |
| 不建议购买 | 重复度 ≥ 0.7 或 可搭配组合数 = 0 | 「衣橱里已有高度相似的 {X}，{Y} 也难找到搭配对象」 |
- [来源: 依据 K-ALG-05（Jaccard 重复度）、K-ALG-06（组合数剪枝）、K-CAP-02（极简衣橱原则）]
